A petri dish made of math.

Anima simulates continuous cellular automata on your graphics card, maps where self-organizing life can exist, and breeds new genomes to find it. Paint into the dish, then watch what the rule does with your mark.

WebGL2 with float rendering is required. This browser or device doesn't support it. Try a current desktop Chrome, Edge, Firefox or Safari.

      One rule, no scripts

      Every cell holds a number between 0 and 1. Each step, a cell looks at a ring of neighbours, averages them with a smooth kernel, and asks whether that average is in a comfortable range. If it is, the cell grows. If not, it shrinks.

      Nothing here is animated by hand. Anything that moves, splits or holds its shape emerges from that loop and your genome.

      U  = (K ∗ A) / Σ K          // ring-shaped kernel
G(U) = 2·exp(−(U − μ)² / 2σ²) − 1
A  ← clamp(A + Δt · G(U), 0, 1)

K(r) = exp(4 − 1 / (r(1 − r)))  // per ring

      Finding life is a search problem

      Most genomes die out, blow up into static, or freeze. Life lives in thin bands of parameter space. Anima looks for them two ways.

      Survey tests a 12 × 12 grid of growth centre and width, using the same seed for every cell, and paints the outcome onto the phase map. Discover is a mutation-and-selection loop that starts from your current genome and climbs toward higher scores.

      1. TrialReseed with a fixed random seed, then run 300 steps on the GPU.
      2. MeasureRead back mass, coverage and activity at the halfway point and the end.
      3. ClassifyExtinct, saturated, static or alive. Alive genomes are scored for steady mass, compact structures and ongoing motion.
      4. SelectDiscover mutates the radius, growth curve and ring weights, keeps the best child, and repeats for ten generations.

      Under the hood

      The simulation state lives in 32-bit float textures. A fragment shader computes each cell's kernel sum, and two textures swap roles every step. At the default settings that is tens of millions of texture reads per step, done in parallel.

      Everything is static files with no framework, no build step and no server, so it runs on GitHub Pages as is. Genomes are shareable through the link button, which stores them in the URL.

      Honest limits

      The automaton is Lenia, created by Bert Wang-Chak Chan. Anima's contribution is the interactive GPU implementation, the phase-map survey and the evolutionary search. The alive-or-not classifier is a heuristic, so a low score doesn't prove a genome is uninteresting, and results depend on the seed. Trials and the survey also depend on your GPU speed.

      Built like software, not a demo

      Anima is an open repository with a tested core, continuous integration and automatic deployment. Every push runs the unit tests, and only a passing build is published to GitHub Pages.

      The pure logic (kernel maths, seeding, the life classifier) lives in one dependency-free file, so the same code runs in the browser, in the test page and in CI. Testing found a real defect in an earlier version: single-ring genomes used only the inner third of the kernel radius. It is fixed and covered by tests.
